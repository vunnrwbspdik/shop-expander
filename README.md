## Overview

Shop Expander increases the visible item slots in Terraria NPC shop windows from the default to a fully scrollable grid showing all shop inventory simultaneously, eliminating the need to scroll through small windows to find specific items when purchasing from merchants with large inventories.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Shop Expander** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Expanded Grid** | NPC shop windows display all available items in a scrollable grid |
| **Bigger Window** | Resizable shop window accommodates large vendor inventories |
| **Search Filter** | Type to filter visible shop items by name for fast shopping |
| **Mod Shop Compat** | Works with all custom NPC shops added by installed content mods |
